# 朋友使用说明

账号与任务配置只能由对应账号自己的 HAR 生成，不能使用别人的会话文件。

## 第一步：准备 HAR

朋友需要在自己的电脑和微信账号下，使用抓包工具获取一份当前版本游戏的
HAR。没有 HAR 或等价登录凭证时，桌面程序无法登录他的账号。

## 第二步：生成账号与任务配置

启动桌面程序：

```bash
python3 gt_studio.py
```

选择朋友自己的 HAR，点击“生成配置”。

生成成功后会显示：

- 账号角色；
- 支持每日福利；
- 是否支持四艺星盘。
- 是否导入招贤。
- 是否导入绮罗锦衣。

## 第三步：运行任务

以后不需要 HAR，直接打开桌面程序运行任务。配置文件与运行日志都会
保存在解压目录中。

需要重新绑定账号时，可以点击“一键清除配置”。该操作只删除账号、任务、
招贤和绮罗锦衣文件，不会删除 HAR 或日志。

## 常见问题

### 提示客户端版本过低

重新抓取当前版本 HAR，并重新生成配置。

### 四艺星盘按钮不可用

当前 HAR 没有包含命令 `6589` 的活动状态。请在官方的四艺星盘页面加载后
重新抓取 HAR。

### 为什么不能直接使用别人的配置文件

那会操作别人的账号。配置文件含有账号登录令牌，不应共享。
